## ✨ Features

- **🌀 Multiple Vector Physics Modes:**
  - **Flow Field:** Trigonometric noise vectors guiding particle velocity streams.
  - **Gravity Well:** Attractor physics pulling mass towards interactive cursor coordinates.
  - **Vortex:** Centripetal rotational forces simulating galactic particle spirals.
  - **Neural Mesh:** Dynamic proximity networking connecting nearby nodes with distance-scaled opacity.
- **🎨 Curated Neon Palettes:** Cyber Neon, Electric Sunset, Aurora Borealis, Cosmic Plasma.
- **⚡ Performance Tuned:** Smooth 60 FPS requestAnimationFrame rendering with customizable particle density (up to 3,000 active nodes).
- **📸 High-Res Artwork Export:** Single-click PNG export capturing unique generative art creations.
